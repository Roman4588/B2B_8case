# Переполнен диск
Если заполнен диск сервера → Проверить свободное место через df -h; Найти крупные файлы и проверить ротацию логов; Согласовать архивирование с владельцем; Вручную архивировать согласованные логи; Проверить восстановление метрики

# Недоступен DNS
Если DNS-сервер не отвечает → Проверить разрешение имени на основном и резервном DNS; Проверить доступность сервера; Передать сетевому инженеру результаты диагностики
