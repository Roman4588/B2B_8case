# Проверка классификации

`evaluation.json` содержит 48 вручную сформулированных учебных событий на русском и английском:
по 12 для каждой из четырёх категорий. Часть событий содержит severity мониторинга,
часть проверяет определение типа по тексту. Присутствуют все три типа и приоритеты P1–P4.

Ожидаемые метки заданы явно. Правило приоритетов опубликовано в README.
Обучающие тексты находятся отдельно в `backend/app/seed/training.json`.
Код классификатора не читает `evaluation.json`. Набор сохранён до реализации классификатора.
Проверяются accuracy каждого поля и доля событий, у которых верна вся тройка.

Обучение и оценка используют авторские данные и общую предметную область;
этот набор не является независимой внешней валидацией. В частности, метки monitoring severity
являются сильным сигналом, поэтому accuracy на этом наборе нельзя переносить на произвольные логи.
Для промышленного применения необходимы реальные исторические события и независимая разметка.
