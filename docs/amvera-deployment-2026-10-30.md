# Сигналис: размещение в Amvera, 30 октября 2026

## Согласованная схема

Владелец согласовал 490 ₽ за 30 дней: существующее приложение B2B, тариф «Начальный Плюс», 0,5 CPU, 1 ГБ RAM, 5 ГБ диска. Тариф применён; автоскейлинг выключен. Новых платных ресурсов нет. [Подтверждение](amvera-evidence/tariff-applied-2026-10-30.png).

Один контейнер содержит Nginx, FastAPI, Celery solo worker с beat, PostgreSQL 17/pgvector, Redis, настоящий Prometheus 3.5 и учебный exporter. Внешний порт только 80; базы и мониторинг слушают loopback. Общий постоянный `/data` хранит БД, модель и загруженные документы. API и worker читают один фактический том.

Корневой amvera.yaml выбирает deploy/amvera/Dockerfile.standalone. Пароль PostgreSQL генерируется один раз в файле /data/.postgres-password с правами 0600. Существующая SQLite импортируется транзакционно до начального наполнения: сохраняются идентификаторы, пользователи и хеши паролей, инструкции, журнал; инструкции переиндексируются. Исходный app.db не изменяется. Повторный запуск проверяет маркер миграции и не дублирует данные.

Супервизор передаёт сигналы всем службам и завершает контейнер при выходе любой из них. Подготовка БД выполняется временным процессом. Единственная embedding-модель находится в worker; API передаёт ему поисковые запросы. Настройки обычного Compose не меняются.

## Локально подтверждено

Проверен именно один контейнер: лимит 950 MiB без swap, 0,5 CPU. Все 12 [HTTP-проверок](amvera-evidence/budget-local-packaging.json) прошли: отдельный engineer без доступа к /users, сессия, Prometheus, смена сценария, рекомендации, ручной журнал без дублей, JSON и перефразированный поиск, Markdown, PDF 60 страниц. Приём PDF 0,031 с, обработка 8,065 с; ready содержит 73 индексированных инструкции.

[Память](amvera-evidence/budget-memory.json): пик достиг лимита 996 147 200 байт, итоговый OOMKilled=false. Запас мал; схема предназначена для демонстрации с небольшой нагрузкой. Это не результат многопользовательского нагрузочного теста. Ранний вариант с резидентной подготовкой БД превышал лимит; он исправлен до финального прогона.

[Ошибка источника](amvera-evidence/budget-source-offline.json) и [восстановление](amvera-evidence/budget-source-recovered.json) проверены реальной приостановкой Prometheus/exporter. [Перезапуск](amvera-evidence/budget-persistence.json) сохранил пользователей, инструкции, четыре файла и неизменный исходный app.db. Проверка миграции использовала резервную копию существующей облачной SQLite; приватные копии и отпечатки паролей в Git не публикуются.

Кэш модели в локальном прогоне был подготовлен заранее; холодная загрузка в Amvera ещё требует проверки. Образ около 1,57 ГБ, данные около 302 МБ. Включённый диск 5 ГБ; платные дополнения не включены.
