# Видеопрезентация «Сигналис»

[Смотреть или скачать видео](media/signalis-presentation.mp4) · [Субтитры SRT](media/signalis-presentation.srt).

Ролик команды «Дейкстра» для кейса №8: команда, мониторинг, классификация, рекомендации,
ручное решение, база знаний, восстановление событий и архитектура. Подготовлен 30 октября 2026 года.

## Формат и проверка

- H.264 + AAC, 1920×1080, 30 кадров/с, 8697 кадров.
- Длительность 289,9 секунды, менее пяти минут; размер 29 768 126 байт.
- Полное декодирование FFmpeg завершилось без ошибок; проверены опорные кадры всех десяти сцен и стык финала.
- Русская синтетическая речь Microsoft `ru-RU-SvetlanaNeural`, темп −5%, через edge-tts.
- Измеренная громкость −20,4 LUFS, true peak −6,6 dBFS; полного субъективного прослушивания не проводилось.
- 66 блоков субтитров совпадают со сценарием; последняя реплика заканчивается на 288,342 секунды.

## Происхождение

Основные экраны взяты из записи учебного стенда проекта. Классификация и база знаний
сняты с настоящего frontend с замороженными синтетическими ответами API и помечены в кадре.
Это демонстрация интерфейса, а не независимая проверка качества моделей.
Приложение не изменялось ради изготовления ролика. Мелкий UI рассчитан на просмотр в полном Full HD.
