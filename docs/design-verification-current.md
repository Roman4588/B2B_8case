# Сигналис: frontend, 12 ноября 2026

## Изменения и границы

Проект F:\B2B_8case, ветка codex/engineer-feedback. Предшествующие незакоммиченные изменения сохранены. Перед правками копия frontend сохранена в outputs/design-baseline, исходный diff в existing.patch. Сравнение подтвердило неизменность существующего diff вне frontend и design.md; api.ts, types.ts, main.tsx и ui.tsx совпадают с исходной копией побайтово. Backend, авторизация, API, зависимости и схема БД не редактировались. Push и публикация не выполнялись.

Сохранена согласованная идентичность: Golos Text, графитовая навигация, светлые поверхности, красный акцент, семантические цвета. Уплотнена сводка; соотношение колонок очереди и разбора 0.85 / 1.15. Описание события предшествует обоснованию классификации. Рекомендации прокручиваются отдельно от действий. Длинный заголовок и факты доступны в ограниченной по высоте области с клавиатурным фокусом. До 1100 px разбор открывается на весь экран; Tab удерживается внутри, Escape закрывает карточку с возвратом к строке. На низких экранах доступна прокрутка всей карточки.

Форма классификации встроена в разбор и сохраняет черновик при polling. После отмены или сохранения фокус возвращается к её кнопке. Оценки имеют текст, иконку, aria-pressed и явный индикатор сохранения. В базе знаний разделены оценки полезности, показан progress текущей обработки, добавлен повтор загрузки документов. Журнал получил состояние загрузки, повтор запроса и читаемые прежние/новые значения. Общие контролы, фокус, отступы и радиусы согласованы; сохранены вход, сотрудники, профиль, источники и все операции. Новые UI/animation-зависимости не добавлялись, декоративная анимация не добавлялась.

## Среда

Изолированный настоящий стек signalis-current-qa: PostgreSQL, API, worker, Prometheus и тестовые данные. Обновлялся только frontend:

```powershell
$env:APP_PORT = '18091'
docker compose -p signalis-current-qa up -d --build --no-deps frontend
```

Адрес: http://127.0.0.1:18091 . Обычный запуск проекта одной командой сохранён.

## Проверки

- npm run build из frontend: TypeScript и Vite успешно. Известные предупреждения lucide-react о директиве use client остаются предупреждениями сборщика; зависимости не менялись.
- Общий финальный Playwright-прогон: 33 из 34 прошли, outputs/design-final-tests.log. feedback-live не нашёл подходящий PostgreSQL-регламент: этот существующий тест удаляет оценённый учебный регламент, и повторные прогоны истощили QA-корпус. Через настоящий API добавлен одноразовый QA-регламент и повторно запрошены рекомендации. После подготовки данных неизменённый feedback-live прошёл: 1 passed, outputs/design-feedback-recheck.log. Все 34 сценария получили успешную проверку; это не один полностью зелёный общий прогон.
- Реальный backend: просмотр события, запись решения, ручная классификация, обе оценки, чтение сохранённого значения через API, агрегаты, аудит, создание и семантический поиск инструкции, импорт и удаление созданного самим тестом документа. Это не проверки на подменённых API.
- Контрактные и стресс-тесты с управляемыми API-ответами отдельно проверяют ошибки, retry, загрузку, пустые результаты, роли, формы сотрудников/пароля, длинное описание, задержки polling и сохранение черновиков. Они не считаются подтверждением backend persistence.
- Все разделы сняты при 1440, 1024, 768 и 390 px. Проверены горизонтальное переполнение, клавиатурный возврат, прокрутка, видимость действий и черновик после автообновления. Дополнительный стресс-тест: длинный русский заголовок и описание при 1440×900, 1024×768, 768×1024, 390×844 и 320×360.
- Контраст десяти основных пар текста/фона рассчитан через браузер: каждая не ниже 4.5:1. Это проверка палитры, не полная сертификация WCAG.
- Независимый review: исправлены удержание фокуса, возврат фокуса после формы, низкий viewport. Повторно просмотрены desktop, tablet, mobile и стресс-снимки.
- Hallmark: sloplint по 15 затронутым исходникам, scope app, modern-minimal, render и kept. Итог: 0 FAIL, 0 REFLEX, 5 WARN. Render инструмента снимает страницу входа; авторизованные экраны проверены отдельными браузерными тестами и просмотрены визуально.

## Разбор предупреждений Hallmark

Пять WARN просмотрены вручную. Длинная кнопка повторной загрузки намеренно переносит текст на узком экране. Выбранные навигация и оценка не являются конкурирующими первичными действиями. Повторяемые рецепты границ/радиусов нужны для единой системы контролов рабочего приложения, а не декоративных одинаковых карточек. У всплывающей справки сохранены тонкая граница и небольшая тень для отделения от страницы. Функция отмены классификации не удалена: literal inline-handler заменён closeEditor с возвратом фокуса, что явно записано для kept-проверки. Заголовок входа уточнён: «Добро пожаловать» → «Вход в Сигналис».
