# Сигналис: персональный доступ и оформление B2B-Center

**Цель:** заменить общий пароль личными аккаунтами, создаваемыми администратором; оформить приложение в графитовой, белой и красной палитре сайта компании.

**Решения:** сохранить React/FastAPI/PostgreSQL и серверные HttpOnly-сессии. Роли: администратор и инженер. Публичной регистрации нет. Первый администратор создаётся интерактивной локальной командой, без пароля по умолчанию. Старый общий профиль отключается миграцией; события и аудит сохраняются. Временные пароли требуют смены до доступа к данным. Отключение и сброс пароля отзывают сессии. Интеграция с корпоративным SSO не входит в задачу.

## Этапы
- [ ] Проверить регрессиями вход по email, запрет общего входа, права инженера, смену временного пароля, отзыв сессий, защиту последнего администратора.
- [ ] Добавить поля Operator и миграцию 0003; вынести маршруты авторизации и управления пользователями в accounts.py, добавить CLI manage.py и Windows-скрипт.
- [ ] Добавить экраны личного входа, смены пароля и сотрудников; обновить палитру и композицию всех страниц по референсу https://www.b2b-center.ru/.
- [ ] Обновить CI, smoke, E2E и документацию для личных учётных записей.
- [ ] Проверить миграцию, серверные тесты, сборку, браузерные сценарии и мобильный экран; сохранить на GitHub.

## Особые проверки
- Email нормализуется, регистр не создаёт дубликатов.
- Отключённый профиль не может использовать ранее выданную сессию.
- Временная сессия допускает только смену пароля, просмотр своего профиля и выход.
- Последний активный администратор не отключается, включая конкурирующие запросы.
- Старые данные сохраняются, общий пароль больше не даёт доступ.
